# 2. Brand Story

BrewFlow is a modern SaaS platform built specifically for coffee businesses.

Unlike generic POS software, BrewFlow understands how coffee businesses operate—from coffee carts and street coffee vendors to kiosks and cafés.

BrewFlow centralizes operations including:

- Point of Sale (POS)
- Inventory
- Purchasing
- Recipe Management
- Payroll
- Employee Management
- Cash Flow
- Reporting
- Analytics

The platform allows business owners to spend less time managing operations and more time growing their business.

# 25. AI UI/UX Guidelines (For Minimax M3 / AI Design Systems)

The software generated from this guideline **must** follow these principles.

## General Principles

- Clean enterprise SaaS interface
- Minimalist layout
- Plenty of whitespace
- Consistent spacing (8px grid system)
- Responsive desktop-first design
- Mobile-friendly components
- Fast-loading pages
- Accessibility (WCAG AA preferred)

## Design Style

Inspired by:

- Stripe Dashboard
- Shopify Admin
- Square Dashboard
- Notion
- Vercel
- Linear

## Layout

- Left sidebar navigation
- Top navigation bar
- Dashboard cards
- Rounded corners
- Clean data tables
- Modern charts
- Soft shadows
- Flat design

## Components

Use:

- Rounded buttons
- Rounded inputs
- Rounded cards
- Soft borders
- Green primary actions
- Brown branding accents

Avoid:

- Heavy gradients
- Excessive animations
- Skeuomorphic UI
- Cluttered interfaces
- Overuse of icons
- Bright saturated colors

## UX Principles

Prioritize:

1. Simplicity
2. Speed
3. Readability
4. Business insights
5. Minimal clicks
6. Clear navigation

Every screen should answer:

- What happened today?
- What needs attention?
- What action should the user take next?
